## Environment pitfalls found (mnaccept)
- In a multi-node hold, `R`/`N` use `srun -N1` without `-w`, so the e9 run (writes `/tmp/mnaccept_J` on node X) and the compare (`N`) can land on different nodes: "dd: failed to open /tmp/mnaccept_J/e9_b10.txt", reported as DIFFERS. Run e9/full in a 1-node hold (as done here), or set `MNACCEPT_TMP` to a shared dir.
- A 30 min hold expired during the 20 min t_mn_grid timeout: e9 then failed with "job expired" (my hold length, not code).
- Some runs wrote the ref symlinks into `~/ntt-wt/t01/ecalc/ref/` (git-ignored).
