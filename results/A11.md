All line counts below are **assumed** (site counts and enclosing blocks, ±50 %) unless marked **measured** (wc / brace-matching of whole files or functions). No timing numbers are claimed.*

**Method.** Names are every `getenv("X")`, `env_int("X")`, `env_on("X")` string in `ecalc/*.c`, `*.h` (script: grep of those call forms; the README's own recipe misses `env_on` and the `setenv` forms). Defaults are taken from the reading line (machine-extracted for ~150, README text for the rest, `auto/derived` where an expression). Status comes from the README row text plus these rules: *launch-line* = set by `e16_headline.sh`, `target_kit.sh`, `mnrun.sh` or the README launch table, or used by the regression scripts; *adopted-default* = default on in code, or a numeric tunable with a code default; *experimental-off* = default off, not rejected; *rejected* = measured, not adopted (README / RESULTS text); *test-only* = debug, print-only, test hook or instrument; *dead* = see section 2. Evidence = the `results/*.md` or RESULTS section the README row cites, else the two result files that mention the name most. The inventory is a draft for the integrator, not a verified audit: status of ~110 tunables is by rule, not by reading each site.

**Scope counts (measured, by script).** 271 environment switches are read by the ecalc C code (excluding 2 external variables `SLURM_NTASKS`, `PMI_SIZE`); a further 30 are read only by `tests/` and `tools/` programs (listed after the table); the launch/model scripts read ~20 more (`MNRUN_*`, `AAC7_*`, `FI_*`, `MN_MODEL_*`, `ECALC_LOG_CLOCKS`, `COMM_SHMEM_IMPL`, `MNACCEPT_TMP`). The code is 22 132 lines in `ecalc/*.c|*.h` (measured) and 7 120 in `tests/*.c|*.h`. PLAN §28 projected 116 → ≈55 switches at 13 016 lines (2026-09-22); the count has since grown to 271 because Phases 12-17 and the S-series added mostly tunables, instruments and rollbacks.
