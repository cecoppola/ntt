# P2 - profile of the combined candidate (A) and a real-size hang soak on SPX (B)

Branch g2 (tools only). Labels: measured / modelled / assumed. Times Eastern. Armed 2026-10-12 07:51.

## Design
- Platform: aac6, `PPAC_MI300A_SPX`, 1 node, 4 APUs. At arm time only ONE SPX node was free (the other was held by another
  user's 8 h job), so A and B run one after the other on the same node, from a single controller (`tools/p2_ctl.sh`), not in parallel.
- Controller: successive holds (<= 45 min, `sbatch` without `-w`, never past 09:58); the first hold runs part A, then part B
  until the hold nearly ends; no new run after 09:45; cancels only its own holds. Marker files per part.
- Part A (`tools/p2a_steps.sh`): clone `~/ntt-cand` (branch cand 0247792, already built, unmodified), env
  `DBIG_SMALL_BOUNCE=1 DIST_GATHER_RAW=2 BS_SEED_PULL=1`, 6.441e10 digits, no digit writes. One `rocprofv3 --kernel-trace` run
  and one unprofiled run (both `ECALC_VERBOSE=2`), same method and scripts as archive:results/O7b.md (`tools/o7b_table.py` top-25 table,
  `tools/o7b_timeline.py` 5 s busy timeline, phase lines from the unprofiled log). Compare with O7b main (init 15.5 s + seed wait
  10.0 s = 25.5 s idle before level 1; total 73.3 s unprofiled). Output `~/p2a/` (summary.txt, log/, rp_64410000000/).
- Part B (`tools/p2b_node.sh`, a copy of `tools/g2_node.sh` without the CPX pool settings): clone `~/ntt-cand-main` (main a448d73,
  unmodified), default switches, 6.441e10 digits back to back. Timeout = 3 x median wall of the OK runs (420 s for the first 3,
  min 60 s). On timeout: gdb all-thread backtrace, `/proc/<pid>/task/*` wchan/syscall, last 50 log lines
  (PR_SET_PTRACER_ANY wrapper as in g2), then kill that single PID. Class per run: OK / HANG / SEGV / VFAIL / OTHER, with VERIFY OK
  required for OK. Output `~/p2b/b/` (runs.tsv: n, time, rc, verify, wall s, class, timeout; totals.txt; hang/; log/ for non-OK
  runs), driver log `~/p2b/driver.txt`.
- Dry run: the p2b loop was run locally with a stub binary (3 OK runs, runs.tsv and totals.txt written).

## Collect
- Markers: `ssh aac6 'cat ~/p2a/DONE ~/p2b/DONE'` (ETA ~08:15 for A; B ends ~09:50).
- A: `ssh aac6 'cat ~/p2a/summary.txt'`. B: `ssh aac6 'awk -F"\t" "{c[\$6]++} END{for(k in c) print k,c[k]}" ~/p2b/b/runs.tsv; cat ~/p2b/driver.txt'`.
