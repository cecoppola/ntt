# Q1 - aac7 standing work-queue runner (tools/aac7q.sh)

Status: built and dry-run in stub mode only (2026-10-11); NOT armed on aac7. Labels: measured / modelled / assumed.

## Design
- Login-node daemon `tools/aac7q.sh` (copy at aac7 `~/aac7q/aac7q.sh`). Single instance (`flock` on `~/aac7q/lock`), `STOP` file, `log`, `heartbeat` (epoch, rewritten every POLL=20 s), `done.tsv`, per-item state in `state/`.
- Queue dir `~/aac7q/queue/*.sh`. Item headers (comment lines): `OWNER`, `NODES` (1-6), `EST_MIN`, `APPROVED=<who/date>` (absent = never run, logged once), optional `NOT_BEFORE`/`NOT_AFTER` (epoch; an item that cannot end before NOT_AFTER is skipped), `EXCLUSIVE=1`, `ALLOW_SLOW=1` (do not exclude aac7-n01).
- Scheduler (each poll): free = 6 - nodes of ALL our jobs (`squeue -u`, running and pending, queue or not). Eligible items sorted largest NODES first (ties by file name); each that fits is started, so one poll can start several. EXCLUSIVE: starts only when none of our jobs run and no other start happens in that poll; while it is active nothing else starts. Starvation guard: an EXCLUSIVE item that waited `EXCL_PATIENCE` (default 3600 s) makes the daemon stop starting other items until it has run.
- Per item (background subshell): `sbatch -p <aac7 partition> -N n --exclusive --gpus-per-node=4 -x aac7-n61[,aac7-n01] -t EST*1.5+5 -J aq_<item> --wrap "sleep"`; wait for RUNNING; pending > 10 min -> `scancel` that hold, item retried after 5 min (max 5, then rc 126). Item runs `env -u OUT -u HOLD SLURM_JOB_ID=<hold> bash item` in `~/aac7q/work` (fixes the S47 OUT-leak bug); timeout 1.5*EST+5 min kills the item's PID tree by PID (pgrep -P), then KILL; hold `scancel`led by id; `<item>.rc` (124 timeout, 125 daemon restarted mid-item, 126 gave up) and `<item>.log` next to the item. A restart after a crash cancels recorded stale holds.
- Idle report: nodes free and nothing startable -> `~/aac7q/IDLE` (since, last, free_nodes, used_nodes, runnable_waiting, note); removed when nodes get used.
- Stub mode `STUB=1`: no Slurm; holds are files in `$AQ/stub` (`stub/ext_x` containing N simulates a foreign job of ours); knobs `POLL`, `EST_UNIT` (s per EST_MIN), `EXCL_PATIENCE`, `PEND_MAX`, `STUB_PEND_S`.

## Dry run (measured, stub, EST_UNIT=2, POLL=1, dir `q1dry`; no real aac7 job)
Queue: 01_four(4) 02_two(2) 10_three(3) 11_two(2) 12_one(1) 20_excl(3, EXCLUSIVE) 30_later(1, NOT_BEFORE +45 s) 40_unappr(no APPROVED) 50_hang(sleeps past the timeout) 99_tooshort(NOT_AFTER too near); a foreign 2-node job present for the first 25 s.
- 01_four started first (4 + foreign 2 = 6). 02_two waited (no fit) until the foreign job left, then ran. After 01_four: 10_three + 12_one packed (3+1), later 02_two, 11_two + 50_hang.
- 20_excl ran only once everything else had ended (waited for quiet). 30_later started after its NOT_BEFORE. 40_unappr and 99_tooshort never ran (logged). 50_hang: TIMEOUT, PID tree killed, rc 124, no leftover `sleep`. All others rc 0; items saw `OUT=unset` although the daemon was started with OUT exported. STOP -> daemon exited after the last item. IDLE written with free_nodes=6 when the queue was empty.
- Not exercised live: real sbatch/squeue paths, pending-timeout path with real Slurm (stubbed only by code reading), drain-after-patience path.

## Arm (coordinator/user, later)
`ssh aac7 'bash ~/aac7q/aac7q.sh start'` (equals `setsid nohup bash ~/aac7q/aac7q.sh run >> ~/aac7q/daemon.out 2>&1 < /dev/null &`). Check: `bash ~/aac7q/aac7q.sh status`; heartbeat age < 60 s; `~/aac7q/IDLE` existence means free nodes with nothing to run. First armed use: put one 1-node approved smoke item (EST_MIN=2) in the queue and check `squeue -u <user>`, the .rc, and that the hold is gone.

## Submit an item (agents)
Copy `tools/aac7q_item_template.sh` to `~/aac7q/queue/<NN>_<agent>_<what>.sh`, fill headers (leave APPROVED empty: the coordinator/user adds `# APPROVED=<who/date>`; write the file under a temporary name and `mv` it in last so the daemon never sees a half-written item). Steps must use `--overlap --mem=0`, no `-w`; the hold is `$SLURM_JOB_ID` with NODES nodes. Results: `<item>.rc`, `<item>.log` in the queue dir; output of your own under `~/<task>/`. To withdraw an item before it runs: delete it.

## Stop
`bash ~/aac7q/aac7q.sh stop` (touch `~/aac7q/STOP`: no new items; exits when running items end). Hard stop: kill the daemon by its single PID (`cat` from `ps -u $USER -o pid,args | grep aac7q.sh`, not pkill -f); the SIGTERM trap cancels active holds and ends runners. Then `squeue -u <user>` must show no `aq_*` job.

## Open issues / assumptions
- Partition name taken from S47 (`192C4G1H_MI300A_RHEL9_A1`, assumed unchanged). Hold `-t` has no `-c 192` (per the prompt; steps use `--mem=0`).
- Pending holds count against the 6-node budget, so a foreign pending job of ours also blocks starts (conservative).
- The daemon does not check page cache/MemAvailable or leftover `ecalc` processes; items that time runs must do that themselves.
