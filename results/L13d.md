## The 576 table (for D2)

**`results/L13d_plan576.txt`**: g = 576, 2.0–6.0 × 10¹³ total digits in 0.01 × 10¹³ steps, one line per size, then every
size where a count changes. Made by `ecalc/tests/plan_sweep.sh 576 2.0e13 6.0e13 0.01e13 results/L13d_plan576.txt` on the
aac6 login node (defaults: auto, 2³¹ cap, MN_GROUPS default 2,4,…,64,192,576).

Columns: `tree` = the tree levels' pieces of node 0's groups (what node 0 prints); `tree_max` = each level's largest group
(the level's wall); `recip`, `div` = the reciprocal's sharded steps and the division's two products (one group each);
`total` = tree + recip + div, `total_max` = tree_max + recip + div; `levels` = per level, node 0's group / the largest.
The categories are mn_model.py's `run(...)['pieces']` (formed pieces; a one-plane product counts 1).

## Design

- `MN_PLAN_ONLY=<total digits>:<g> ./ecalc` (argv[1] optional; `MN_PLAN_QUIET=1`: the summary line only). Hooked in
  ecalc.c's main after the plane-cap switch and the pools' sizing, before `rns_init`: no device, no communicator; `_exit`.
- New `ecalc/mn_plan.c`, `ecalc/mn_plan.h`. The decisions are the code's own functions:
  - rns_dist.c: `mn_grid_shape` (mn_grid's one-plane/grid choice, extracted unchanged), `db_grid_shape` (mul_grid's,
    extracted unchanged, with `split_grid`/`b_fits`), `grid_piece_skipped` (the two cuts, now used by mul_grid, mn_grid and the
    plan), exported through `rns_dist_mn_plan` / `rns_dist_db_plan`; `rns_dist_plan_pools` gives b_fits the pools rns_init
    would make (`rns_plane_pool_bytes`), `rns_dist_plan_cap_test` = MN_TREE_LOGN_TEST without the device release.
  - newton_db.c: `newton_chain_next` (the anchored chain, from recip_db2 / recip_mn), `newton_mn_chain_start` (the sharded
    part's start), `newton_mn_x1_level` (X1's group rule as a function of g; `x1_level` now calls it).
  - mn.c's schedule: `mn_groups_parse`; the tree's walk (tree_level / tree_level_k Horner order) is mirrored in mn_plan.c.
- Predicted (the only prediction): operand sizes. Q(a, b) = a…(b−1) → log10 by `lgammal`; P = Q · f(a, b) (P/Q = e − 1 at
  a = 1, ~1/a above); r has j + 1 limbs at the step to j; d has `D_EST(j)` limbs; S = Q e; X = dl + 1 limbs.
- `ecalc/tests/plan_sweep.sh` (the table), `ecalc/tests/plan_compare.py` (a real run's product lines against the plan's).
